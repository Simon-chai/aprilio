APRILIO · 课堂模式设计原型

上课了：把「课中 40 分钟」装进 aprilio

现有功能全部服务「课后案头」（成绩、报告、照片），课堂本身是空白。课堂模式是一个全屏沉浸界面： 依据课表感知「现在该上哪个班的课」，把 点名 → 点评 → 小组竞赛 → 下课小结 串成一条课堂叙事， 所有记录直接落入既有的表现流水与评价报告素材池。数据为演示模拟，正式版从花名册与课表读取。

P0 · 点名台

智能点名

Smart Pick

老虎机式抽取，落定即出学生卡。三种权重：均匀 / 关注沉默（未点天数加权）/ 全员轮询。

差异化：点名历史与发言权重由表现流水推导，零新增表；点名落点直接进入快捷记表现。
P0 · 大屏

座位表课堂

Seating Board

全班按座位网格铺开，点头像两步记表现（维度→倾向），+1 飘字全班可见；支持热力图、换座、缺勤标记。

借鉴：iDoceo 座位表（王牌）× ClassDojo 课堂模式。投影模式隐藏教师侧栏、字号放大。
P1 · 竞赛

小组积分赛

Group Race

座位分组的实时积分 PK（发言/纪律/合作/作业），组间排行与个人红花榜一键切换。

补齐：CLASS_MANAGEMENT_DESIGN 自己排期的 P2 红花榜在此落地；分数为流水聚合、不单独落库。
P2 · 收口

下课小结

Lesson Digest

下课铃一响：本节课统计、沉默预警、时间线回放，AI 生成小结存入班级动态，成为评价报告素材。

闭环：课堂记录 → student_behavior_records → 评价报告（report-ai）数据入口，一课一档。
① 点「开始上课」进入课堂（计时开始） ② 点名页：空格 抽人，试试「关注沉默」 ③ 座位页：点头像记表现，开「热力」看分布 ④ 小组页：给各组 +1，切「红花榜」 ⑤ 点顶栏「下课」出小结，让 AI 写一段 ⑥ 右上「投影」模拟教室大屏 空格 抽人 · 1~4 切页 · Esc 返回

落库与集成说明（原型 → 正式版）

能力数据基础迁移
节次感知（现在是哪个班的课）timetables / timetable_slots / timetable_exceptions + semesterOfDate()零迁移，与首页课表面板共用 buildMyDays 投影
点名点名历史 = student_behavior_records 的一条 neutral 流水（维度「课堂表现」，备注「课堂点名」）零迁移；「N 天未点」由流水实时推导，不存冗余
座位表新增轻表 seatings(class_name, semester, row, col, student_id)；P0 无表时按学号序默认排布1 张轻表；归档班级随删（与课表同策略）
记表现student_behavior_records + behavior_dimensions（作业/成绩/课堂/劳动），评语走 behavior-ai 推荐沉淀零迁移，复用 QuickBehaviorPopover 保存逻辑
小组积分组 = 座位列映射；组分 = 本节课表现流水实时聚合，不落独立分值表零迁移（下课小结存档后，聚合值随小结快照固化）
下课小结新增轻表 lesson_sessions(class_name, date, period, subject, digest_md, stats_json)；AI 文本走 report-ai 同款增强层（无 AI 回退数据版）1 张轻表；小结合并进评价报告素材区间
