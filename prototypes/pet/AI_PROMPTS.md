# AI 生成宠物素材 · 提示词手册

配合 `pet-raster.html`（贴图装配台）使用。目标：**一张图产出多个部件，切片后组装成一个会动的形象。**

## 0. 先说清楚 AI 能做到什么

| 能做 | 做不到 |
| --- | --- |
| 在同一张图上画出多个部件（构图能力足够） | 直接输出带透明通道的图（各家文生图都是不透明 bitmap） |
| 保持一张图内的风格、配色基本统一 | 精确保证各部件之间的装配比例（它不知道角色真实结构） |
| 按「纯色背景 + 网格排布」的指令构图 | 保证部件边缘干净到可直接叠加（会有杂边，需要抠图容差） |

所以现实路径是：**AI 出素材板 → 工具切片 + 抠图 → 人工摆位微调**。
AI 负责「画得好看」，分层与动作由工具和人完成。这条链路已经被 `pet-raster.html` 打通，不用手工开 PS。

## 1. 核心思路：素材板（parts sheet）

不要一张图一个部件（一致性差、生成次数多），也不要「一张整图然后自己切」（AI 生成的是扁平图像，没有图层信息）。

**用一张 3×3 的素材板**，9 个格子按固定顺序放部件，切片器按同样顺序自动映射：

```
① 身体（不含头、不含尾）   ② 头（含脸、口鼻、鼻子、胡须）  ③ 尾巴
④ 睁开的眼睛               ⑤ 弯月形笑眼                    ⑥ 闭着的眼睛
⑦ 闭合的嘴                 ⑧ 张开的嘴（含舌头）            ⑨ 一只耳朵
```

- 眼睛和耳朵**只画一侧**，切片器会自动水平镜像补出另一侧（正面视角下左右对称）
- 头部**不要画耳朵**——耳朵由第 ⑨ 格单独提供，否则耳朵被焊死在头部贴图上，耳朵抖动这个动作就做不出来了
- 3×3 是模型最能稳定把握的网格密度；4×4 以上每格太小，部件容易糊在一起
- 网格可以比 3×3 大：切片器按「身体·头·尾·睁眼·笑眼·睡眼·闭嘴·张嘴·耳·肚皮·腮红·口鼻」的顺序继续往下取格子，多余的格子留空即可

## 2. 背景色怎么选（最容易翻车的一步）

抠图靠「背景是纯色」，所以要挑一个**角色配色里绝对不会出现的颜色**：

| 角色主色 | 推荐背景 |
| --- | --- |
| 橙、棕、白、灰、黑（猫狗兔等） | 纯品红 `#FF00FF` |
| 含粉、紫、品红 | 纯绿 `#00FF00` |
| 含绿 | 纯品红 `#FF00FF` |

不要用白背景（浅色毛发抠不干净）、不要用渐变或场景背景。

## 3. 主提示词（中文，适配即梦 / 可灵 / 通义万相 / SD / Flux）

> 一张 2D 动画角色素材拆解图。纯品红色背景（#FF00FF），画面被均匀划分为 3×3 共 9 个等大网格，
> 每格正中央放置一个独立的角色部件，部件之间互不重叠、四周留出充足空白。
>
> 第一行：① 完整的身体（不含头部、耳朵和尾巴）② 头部（含脸部、口鼻、鼻子、胡须，不含耳朵）③ 尾巴
> 第二行：④ 睁开的眼睛 ⑤ 弯成弧形的笑眼 ⑥ 闭着的睡眼
> 第三行：⑦ 闭合的嘴 ⑧ 张开的嘴（含舌头）⑨ 一只耳朵（单独画，不要长在头上）
>
> 所有部件来自同一只【角色描述】，风格统一：【风格描述】。
> 部件按真实比例绘制，色调完全一致，光源统一来自左上方，无投影、无描边、边缘清晰锐利，
> 线条粗细一致，正面视角，左右对称。
>
> 不要任何文字、标签、数字、网格线、水印或装饰元素，不要出现完整角色拼合图，不要场景背景。

**负面提示词**

> 文字, 标签, 数字, 水印, 网格线, 拼合完成的完整角色, 场景背景, 投影, 阴影, 模糊边缘,
> 锯齿, 比例失调, 风格不统一, 多个角色, 肢体残缺, 低分辨率

## 4. 主提示词（英文，适配 Midjourney / DALL·E / SDXL / Flux）

> character parts sheet for 2D animation, flat plain magenta background (#FF00FF),
> the canvas is evenly divided into a 3x3 grid of nine equal cells, each cell contains exactly one
> isolated body part centered with generous padding, parts never touching or overlapping.
>
> row 1: full body without head, ears or tail / head with muzzle, nose and whiskers, no ears / tail
> row 2: open eye / curved happy eye / closed sleepy eye
> row 3: closed mouth / open mouth with tongue / a single standalone ear
>
> all nine parts belong to the same 【character】, consistent art style: 【style】,
> true proportions, identical color palette, single light source from the upper left,
> no cast shadows, no outlines, crisp clean edges, uniform line weight, front view, bilaterally symmetric.
>
> no text, no labels, no numbers, no grid lines, no watermark, no decorative elements,
> no fully assembled character, no scenery background, no background elements

**Midjourney 追加参数**：`--ar 1:1 --style raw --s 50 --no text, watermark, grid lines, shadows`

`--style raw` 和较低的 `--s` 是为了减少模型自作主张的风格化，提高可控性。

## 5. 风格描述块（替换提示词里的【风格描述】）

| 风格 | 可替换文本 |
| --- | --- |
| 扁平插画（推荐，最贴合现有设计系统） | 扁平矢量插画风，干净色块，少量高光，现代 App 吉祥物质感 |
| 厚涂卡通 | 厚涂卡通风格，柔和笔触，温暖色调，细腻光影过渡 |
| 日式动画 | 日式赛璐璐上色，清晰线稿，平涂加一层阴影 |
| 3D 渲染 | 3D 渲染风格，柔光材质，次表面散射，皮克斯动画质感 |
| 水彩 | 水彩手绘风，纸张纹理，边缘略有晕染 |

**角色描述**示例：`圆润可爱的橘色小猫，大眼睛，短腿，圆耳朵`

想在同一只角色上连续生成多个素材板时，**固定风格描述的文字和顺序**，并尽量固定 seed（如果工具支持）。

## 7. 参数建议

| 工具 | 建议 |
| --- | --- |
| 即梦 / 可灵 / 通义万相 | 比例 1:1，分辨率 1024 以上；负面词填第 3 节那段 |
| Midjourney | `--ar 1:1 --style raw --s 50 --no text, watermark, grid lines, shadows` |
| SD / Flux（本地） | 步数 25~30，CFG 5~7，加负面提示词；1024×1024 起步 |
| 通用 | **分辨率至少 1024×1024**（每格 341px）；要更精细就 1536 或 2048，每格越大抠图越干净 |

一次通常出不来理想结果，**多出几张挑**；有 seed 概念的工具固定 seed 后只微调提示词，便于迭代。

## 8. 进阶：逐部件生成（一致性最好，但要更多次生成）

素材板的问题是一张图里 9 个部件的一致性完全靠模型自觉。追求正式形象时改成两步：

1. **先生成一张完整的角色立绘**，反复调整到满意——这张图定下了风格、配色、比例
2. 用它的**图生图 / 局部重绘**逐部件生成，每次只画一个部件：

> 基于参考图中的同一角色，单独绘制【部件名】，正面视角，纯品红背景（#FF00FF），
> 严格保持与参考图完全一致的艺术风格、配色、线条粗细与光照方向，
> 画面中只出现这一个部件，居中，四周留白，不要其他任何元素

重绘强度（denoise / strength）建议 **0.4~0.6**：太低不改变构图，太高会丢掉风格一致性。
SD 系的「局部重绘 + 蒙版」、即梦的「参考图」、Midjourney 的 `--cref` 都能做这件事。

## 9. 拿到图之后

1. 打开 `pet-raster.html`，把素材板图拖进右侧「素材板切片」区域（也可点「选素材板」）
2. 设行列数（默认 3×3）。拖进来时工具**已从四角自动取好背景色**，并给出建议容差
3. 核对背景色：不对就手动改色值，或点「四角取色」重取。若提示「色差偏大」，说明背景不均匀或有部件压到角上
4. 调「抠图容差」：边缘残留杂色就调大，部件被抠出洞就调小。默认 0.18 一般够用
5. 调「边缘羽化」：让抗锯齿边缘平滑过渡，别留硬边
6. 看下面的**映射清单**确认每格对应哪个部位（默认按第 1 节顺序，超出的格子显示「空」）
7. 左右对称的角色保持勾选「自动镜像」；不对称就取消，自己补另一侧
8. 点「切片导入」→ 得到 9 个部件 + 4 个镜像层，按内置骨架粗摆位
9. 逐个拖拽微调位置与缩放，必要时调锚点 → 切状态看动作 → 导出 pet.json

**关于「自动镜像」**：眼睛和耳朵只画一侧，导入时会水平翻转补出另一侧，缩放和位置自动对称。
所以素材板里**不要**左右各画一只眼——那样反而会多出两层互相打架。

**关于「抠图容差」的档位感受**：
容差本质是「这个像素里有百分之多少是背景色」的阈值。所以容差 0.18 = 低于 18% 背景成分的像素直接判为透明；
介于容差和容差+羽化之间的像素会得到半透明 alpha，并按 alpha 反解出前景色（去掉边缘的品红污染）。
调太大，浅色毛发、半透明的高光会被一起抠掉；调太小，边缘会留一圈底色。

**导出后别急着用**：切片只是把「一张图拆成部件」，部件的相对大小和位置是 AI 画的、不是它算的。
内置骨架只是让 9 个部件别叠在一起，**位置一定要自己拖一遍**，否则会出现头漂在身体外面、眼睛长到额头上这类问题。

## 10. 验收清单

- [ ] 9 个格子都是**独立部件**，没有出现拼合过的完整角色
- [ ] 背景是**单一纯色**，没有渐变、阴影、纹理
- [ ] 各部件色调一致、线条粗细接近（不一致就重新生成或局部重绘）
- [ ] 眼睛和耳朵是**单只**、正面视角（这样镜像才成立）；不要左右各画一只
- [ ] 头部**没有长出耳朵**（耳朵是第 ⑨ 格单独提供的，否则耳朵抖动做不出来）
- [ ] 身体不含头、耳朵和尾巴（否则会和头部层重叠穿帮）
- [ ] 分辨率 ≥ 1024，边缘锐利、没有明显 JPEG 压缩痕迹
- [ ] 部件之间没有互相接触（接触了切片会切到隔壁）
- [ ] 每格部件都**完整落在格子里**，没有被格子边界切掉一角

**最常见的失败**：模型偷懒直接画了一整只拼好的猫。这时把提示词里
「不要出现完整角色拼合图」「每个格子只有一个孤立部件，部件之间互不重叠」加重，或换成 2×3、2×2 更少的格子重试。

**第二常见的失败**：背景不纯——模型自作主张加了渐变、地面阴影或柔光。
切片器会提示「角间色差偏大」；这时把提示词里「纯品红色背景」和负面词
「渐变, 场景背景, 投影」加重，或换一个背景色重试。
