# 班级管理日常表现分类时间轴设计规范

> 文档状态：设计完成，待评审  
> 日期：2026-09-05  
> 目标：在班级详情页（`ClassDetailView.vue`）新增「日常表现」Tab，以「分类胶囊 + 时间轴流水」的形式聚合展示本班所有学生被记录的各项日常表现，支持按大类筛选、按评价倾向过滤、按具体学生及具体事项下钻，并联动「快捷记表现」实现班级场景的极速录入与学生个人档案跳转闭环。

---

## 1. 背景与业务价值

在已落地的个人学生档案查看功能中，班主任可以在单个学生详情页（`StudentDetailView`）中通过时间线查看该生的全部成长轨迹。然而在日常班级管理实践中，班主任的核心工作视角往往是**以班级为整体单位**的：
1. **班级全局掌控**：班主任需要宏观了解今天/近期班级里发生了哪些事情，哪些学生受到了表扬，哪些学生出现了需关注的问题；
2. **分类审视与归因**：班主任经常需要按领域专项排查（例如本周的「学习表现」有哪些同学波动，或者近期的「行为习惯」有哪些好人好事）；
3. **学生个体跳转与快速闭环**：在班级时间流中发现某学生异常或优秀事迹时，能一键直达该学生的个人成长档案，或直接在班级中为本班学生补录日常表现。

因此，本设计在班级管理（`ClassDetailView`）中引入按分类的聚合时间轴，补齐班级维度的行为事实汇聚与消费能力。

## 2. 页面与组件交互设计

### 2.1 班级详情页（ClassDetailView）Tab 扩展

在班级详情页中，将现有的双 Tab 结构升级为三 Tab 结构：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [ 学生条目 (42) ]    [ 班级相册 (18) ]    [ 日常表现 (65) ● ]           │
├────────────────────────────────────────────────────────────────────────┤
│ (Tab 1: 原学生列表与搜索)                                               │
│ (Tab 2: 原班级公共与学生个人相册)                                       │
│ (Tab 3: 班级日常表现分类时间轴 ClassBehaviorTimeline，含快捷记表现联动)    │
└────────────────────────────────────────────────────────────────────────┘
```

- **Tab 标签与徽标**：展示 `日常表现 (N)`，`N` 为当前班级所有学生产生的表现记录总数。
- **概览卡片更新**：顶部第三张概览卡片「档案动态」文案同步呈现本班学生数与表现记录数（如 `42 名有效学生 · 65 条表现记录`）。

### 2.2 班级日常表现时间线组件（ClassBehaviorTimeline.vue）

#### 1. 控制工具栏（双层过滤）
位于时间线上方，分为主分类切换行与次级交叉筛选行：

- **顶层：分类主筛选胶囊（Category Pills）**：
  - `全部 (65)`
  - `📚 学习表现 (32)`（`study`）
  - `🌱 行为习惯 (28)`（`behavior`）
  - `✨ 其他表现 (5)`（`other`）
  - 点击对应胶囊后，时间轴即时切换至该分类下的表现流水，选中态采用高亮背景（`bg-primary text-white`）。

- **次层：多维复合筛选与操作栏**：
  - **评价倾向过滤胶囊**：
    - `全部` / `👍 表扬 (40)` / `⚠️ 待改进 (20)` / `➖ 中立 (5)`（支持快速按评价性质过滤）。
  - **学生筛选下拉框**：
    - 选项包括「全部学生」以及当前班级内有记录或全部在读学生；选中特定学生后仅展示该学生的记录。
  - **事项细分下拉框**：
    - 选项包括「全部事项」以及当前已被记录的维度（如“作业情况”、“课堂表现”、“劳动情况”等）。
  - **快捷操作按钮**：
    - 右侧提供 `[+ 记表现]` 次级/主按钮，点击触发班级快捷记表现弹窗。

#### 2. 时间线流水展示（Timeline Stream）
- **按日期降序聚类**：同一天（`recorded_date`）的记录合并到同一日期节点，展示形如 `2026-09-05 · 4 项表现`；
- **发丝基线与状态节点**：左侧贯穿纵向发丝线（`bg-hairline`），节点圆点根据倾向呈现色彩指示（表扬为绿色，待改进为橙色，中立为浅灰色）；
- **表现卡片内容要素**：
  1. **学生姓名胶囊**：醒目标记 `🧑 林知远`，悬浮呈现微底色，点击后触发路由跳转直达 `/students/:id` 学生个人档案页；
  2. **维度快照标签**：展示如 `课堂表现`、`作业情况` 灰色小胶囊；
  3. **倾向徽章**：`👍 表扬`（浅绿）、`⚠️ 待改进`（浅橙）、`➖ 中立`（浅灰）；
  4. **记录时分**：右侧灰色弱化字体展示具体记录时间（如 `14:30`）；
  5. **评语正文**：完整呈现教师评语或 AI 生成沉淀的描述文本，字体舒适易读。

#### 3. 空状态与反馈
- **全班无任何表现记录**：展示 `EmptyState` 风格卡片，文案“本班暂无日常表现记录”，并提供“+ 记表现”引导按钮；
- **筛选后无匹配记录**：居中展示灰色提示文案“没有符合筛选条件的表现记录”。

## 3. 数据模型与服务层契约

### 3.1 类型扩展（src/types/index.ts）

```ts
/** 分类文案与展示字典 */
export const BEHAVIOR_CATEGORY_LABEL: Record<BehaviorCategory, string> = {
  study: "学习表现",
  behavior: "行为习惯",
  other: "其他表现",
};

/** 班级聚合表现记录（在流水基础上扩展学生主体信息） */
export interface ClassBehaviorRecord extends StudentBehaviorRecord {
  student_name: string;
  student_no?: string;
  student_gender?: Gender;
}
```

### 3.2 数据库与存储层接口（src/lib/db.ts）

新增方法 `listBehaviorRecordsByClass(className: string, limit = 200): Promise<ClassBehaviorRecord[]>`：

- **Tauri SQLite 环境实现**：
  ```sql
  SELECT 
    r.*,
    s.name AS student_name,
    s.student_no,
    s.gender AS student_gender
  FROM student_behavior_records r
  INNER JOIN students s ON r.student_id = s.id
  WHERE s.grade_class = ?
  ORDER BY r.recorded_date DESC, r.created_at DESC, r.id DESC
  LIMIT ?
  ```

- **浏览器演示/单测内存态（Memory Store）实现**：
  1. 找出 `store.students` 中 `grade_class === className` 的学生集合，构建 `id -> student` 映射表；
  2. 过滤 `store.behaviorRecords` 中属于该班学生的流水记录；
  3. 将匹配记录组装上 `student_name`、`student_no`、`student_gender`；
  4. 按日期与 ID 倒序排列后按 limit 截取返回。

## 5. 异常与边界场景处理

1. **转班/历史数据一致性**：`StudentBehaviorRecord` 本身通过 `student_id` 关联学生，按当前班级学生实时内联查询。若学生转入新班级，其档案表现历史完整跟随，并在新班级表现流中体现当前归属；
2. **大类无记录**：若某个分类（如“其他表现”）暂无记录，分类胶囊计数展示 `0`，点击后正常展示“没有符合筛选条件的表现记录”友好提示；
3. **极长评语文本**：评语正文支持自然换行（`whitespace-pre-wrap`、`break-words`），不会造成卡片横向溢出；
4. **组件卸载与定时器清理**：如有 toast 提示或防抖计时器，严格在 `onBeforeUnmount` 中注销清理，杜绝内存泄漏。
