交互可发现性样式提案

目标只有一个：让按钮、Tab、胶囊这些「可操作语义」在不悬浮鼠标的情况下也被一眼识别。 现状的设计语言（单一 Action Blue + 发丝线 + 克制动效）非常好，问题不在颜色本身， 而在「可点」与「静态」的视觉权重几乎相同。以下逐页对比「现状 → 方案 A / B / C」， 三个方案共享一套渐进谱系：A 用描边、B 用蓝底、C 用渐变能量线， 都不引入第二强调色，风格保持科技感、简洁、轻盈。所有示例可直接悬浮体验。

✓ 决议（2026-09）：采纳方案 C「渐变能量线」并已落地；侧边栏不照搬方案 C，改用专属的「提起感」选中效果（字体轻微放大 + 向左上偏移 + 浅影托底），见 01 侧边导航。修订：班级卡片上「图标+文字」胶囊会挤压班级名，已改为——班级名独占标题列、点击名称直接改名（悬浮给说明），归档/删除收进卡片右上角「⋯」菜单。
图标即操作。编辑 / 归档 / 删除 / 导入 / 新建全部是无文字的 28~32px 灰图标，说明只存在于 title 悬浮提示——用户不知道它们存在，更不知道它们能点。
选中态黑白。Tab 与分段控件的选中态用 bg-ink 黑底白字，与「蓝 = 可交互」的语言脱节；黑块沉重，也与轻盈的方向相悖。
次级按钮像禁用。pearl 灰底 + hairline 描边按钮与静态信息卡片几乎同权重，「历史备忘」「等级映射」这类真实操作淹没在页面里。

线框强化

Quiet Outline

不动颜色体系，用 1px 主色描边与图标补文字把可点性说清楚：图标按钮升级为带描边的常显控件，关键低频操作（编辑/归档/删除）改为「图标 + 文字」描边胶囊，组内选中 = 主色描边。

方案 B

蓝色信标

Blue Signal

把「操作层」整体染成蓝信号：可点元素常驻 primary-soft 蓝底、hover 翻转为实底。信息黑白灰、操作全蓝，界面即刻分层，扫一眼就能圈出所有能点的地方。

可发现性提升 ★★★ 实现成本 低（换底色即可） 规范冲突 无，需约定蓝底面积 ≤ 20% 适合 操作密度高的工具型页面
方案 C · ✓ 已采纳

渐变能量线

Energy Line

科技感最强的一档：主路径操作用 primary → 亮蓝微渐变、渐变描边、hover 光晕与渐变指示线。仍然只有一个蓝，但用「渐变 + 光」让它看起来在发光。

可发现性提升 ★★★ 实现成本 中（渐变边框 trick） 规范冲突 需放宽「仅两处阴影」为「交互光晕」 适合 对外展示 / 品牌升级期

落地建议

原则：「常显但弱化」优于「悬浮才出现」。hover-only 可以保留给熟练用户的快捷路径，但可发现性必须由常显态承担。三个方案不互斥——推荐 A 或 B 做基线，C 的渐变主按钮可以按页面逐个引入。
