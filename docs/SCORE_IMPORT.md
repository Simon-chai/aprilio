# 考试管理与成绩导入

班级管理的学业成绩入口：把 Excel/CSV 成绩单批量导入为一次「考试批次」，成绩自动关联到
学生档案与班级总览。本文说明功能用法与设计要点（实现：`src/lib/scores.ts`
+ `src/components/ImportScoreDialog.vue` + `src/components/ExamScorePanel.vue`
+ `src/components/StudentScorePanel.vue` + Agent 工具 `import_score_sheet`）。

## 功能入口

| 入口 | 行为 |
| --- | --- |
| 班级详情页「考试成绩」Tab | 考试批次列表 + 单次考试明细（学生 × 科目 + 总分）+ 按学生总览矩阵 |
| 班级详情页「考试成绩」Tab 工具行里「按学生总览」右侧的「导入成绩」图标 | 打开导入对话框（智能识别），可指定考试名与考试时间；自动带上班级上下文，避免同名学生跨班误匹配 |
| 学生详情页「成绩」Tab | 该学生历次考试的成绩（按考试时间倒序，自动关联） |
| 对 AI 助手说「帮我导入成绩单」 | 助手经 `import_score_sheet` 工具直接导入（确认门后） |
| 「导入花名册」选中一份成绩单 | 检测到成绩单后提示「转为成绩导入」，一键交接（见下文） |

## 数据模型（收敛在初始建表迁移中）

```
exams        id, class_name, name, exam_date, note, created_at, updated_at
             -- 一次考试 = 一批成绩；班级沿用 grade_class 文本口径
exam_scores  id, exam_id, student_id, subject, score, grade, created_at, updated_at
             UNIQUE(exam_id, student_id, subject)  -- 导入天然幂等
```

表结构与全库一起收敛在 lib.rs 的单一初始建表迁移里（软件未分发、只有本地调试在用，
不做增量迁移）；本地调试库建于该结构之前时，删除 `aprilio.db` 重启应用重建即可。

要点：

- 每批次成绩必须指定**考试名 + 考试时间**（可从成绩单智能提取，也可手动填写）；
  同一班级「考试名 + 考试时间」相同的批次自动复用——重复导入同一份成绩单只更新成绩，
  不产生重复考试
- 科目是**自由文本**（导入时按表头识别归一：「数学成绩」→「数学」），不做科目字典表——
  小学场景科目少而稳定，先保持轻量；总分/排名等汇总列不导入，由系统按明细计算
- `score` 存数字分；`grade` 存文字（等级制「优/良」、缺考、免考等），二者至少其一
- 删除学生连带删除其成绩；删除班级连带删除班级考试批次与成绩（成绩暂不进回收站快照，
  后续如有需求再扩展）；恢复回收站条目不恢复成绩

## 成绩单识别（智能导入核心）

与花名册导入同构（复用 `RosterTable` 解析与姓名列识别），额外识别三类信息：

1. **科目列**
   - 表头命中科目关键词（语文/数学/英语/科学/道法…或「XX成绩/分数」）→ 科目列，
     归一化科目名；命中排除词（学号/电话/日期/班级/姓名…）直接出局
   - 总分/总评/平均/排名等汇总列永不作为科目
   - 无表头或表头不标准时按**内容特征兜底**：绝大多数单元格是 0~1000 的数字 → 视为科目列
     （长数字如手机号/学号/年份天然被 0~1000 值域排除）
2. **考试名 / 考试时间**：从被剔除的标题行（「三年级二班2026年秋季期中考试成绩单」）提取
   （剥掉「成绩单/分数表」等表类后缀），或从「考试日期」列取首个非空日期；
   都没有 → 对话框默认「空 + 今天」，Agent 工具可传 `exam_name` / `exam_date` 指定
3. **姓名列**：复用花名册的规则打分 + AI 识别（置信度低时对话框要求人工选择、
   Agent 工具返回候选列）

已配置模型时叠加一次 AI 结构识别：把标题行与各列表头/示例值交给模型，返回
`{name_column, subjects, exam_name, exam_date}`；列号经规则校验防幻觉，失败自动回退规则结果。

## 导入规则

- 学生匹配：`student_no` → 班级内唯一姓名 → 全局唯一姓名；学号已存在但姓名不同 → 跳过
  （与花名册导入同一防线，避免把成绩写到他人档案上）
- **成绩单即花名册**：成绩单里有而档案里没有的学生**自动建档**（姓名 + 班级 +
  成绩单学号或 `S<时间戳>` 临时学号），Agent 工具可用 `auto_create_students=false` 关闭
- 成绩逐条 upsert（考试 × 学生 × 科目唯一），单条失败不影响整批；逐行/逐条给出原因
- 浏览器演示态仅支持 CSV/TSV/TXT；桌面端支持 XLSX/XLS 等全部表格格式（复用
  `roster_read_table` / `roster_read_text` 解码通道，语义识别在前端）

## 花名册入口的成绩单分流

「花名册智能导入」最常见的起点就是一份成绩单。两条路径都做了识别：

- **对话框**：`ImportRosterDialog` 智能模式下检测到科目列时展示横幅
  「这更像一份成绩单」→「转为成绩导入」把已解析表格交接给 `ImportScoreDialog`
  （或「仍按花名册导入」忽略）
- **Agent 工具**：`import_student_roster` 加载文件后先做成绩单检测，命中即转入
  `runSmartScoreImport` 管道，一次完成「学生建档 + 智能生成考试批次 + 成绩关联」，
  并在回复里说明两件事都做了；置信度低时仍按花名册导入（宁缺勿滥）

## Agent 行为

- **工具** `import_score_sheet`（dangerous，需 `confirm:true` 确认门）：
  1. `file_path` 缺省时弹出系统文件选择框；浏览器演示态明确报错
  2. 底层即智能成绩导入管道（`runSmartScoreImport`），与对话框行为一致
  3. 参数可覆盖自动识别：`exam_name` / `exam_date` / `class_name` / `name_column` /
     `auto_create_students`
  4. 汇总回复：考试批次（新建/复用 + 名称 + 时间）、识别科目、成绩条数、
     匹配/建档/跳过/失败计数与样例
- 成绩已关联到学生档案后，助手可引导学生去「班级管理 → 考试成绩」或学生详情页查看

## 设计约束

- 与花名册导入共用文件解码、表格解析与姓名列识别（`src/lib/roster.ts`），
  `scores.ts` 只做成绩语义（科目列 / 考试信息 / 成绩单元格 / 学生匹配）
- 考试批次幂等：`findOrCreateExam` 按（班级，考试名，考试时间）复用；
  成绩幂等：`upsertExamScore` 按唯一键覆盖
- 日志只记计数与文件路径，不落学生姓名/成绩等隐私字段
- `RosterTable.titleText`：表头嗅探剔除的标题行文本被保留下来供考试信息提取，
  花名册导入不受影响

## 验收清单

- [ ] 班级详情「考试成绩」Tab：导入一份含标题行的成绩单 → 考试批次自动带名与时间
- [ ] 导入对话框：考试名/时间可手动修改；总分列被忽略；缺考显示为文字
- [ ] 重复导入同一份成绩单 → 不产生重复考试、不重复建档，成绩更新
- [ ] 改成绩单里的分数重导 → 对应学生成绩被更新；学号相同姓名不同 → 跳过
- [ ] 成绩单里的新学生 → 自动建档且出现在学生列表（带成绩单学号）
- [ ] 班级总览矩阵：每个学生每次考试的总分正确（含纯等级列显示「优」）
- [ ] 学生详情「成绩」Tab：历次考试按时间倒序，单科与总分正确
- [ ] 「导入花名册」选一份成绩单 → 横幅出现，「转为成绩导入」可交接
- [ ] 对助手说「直接导入成绩单 <路径>」→ 确认门拦截后按成绩导入并生成考试
- [ ] 删除考试批次 → 成绩一并删除，学生档案不受影响；删除学生 → 其成绩清除
