# 考试管理与成绩导入

班级管理的学业成绩入口：把 Excel/CSV 成绩单批量导入为一次「考试批次」，成绩自动关联到
学生档案与班级总览。本文说明功能用法与设计要点（实现：`src/lib/scores.ts`
+ `src/components/ImportScoreDialog.vue` + `src/components/ExamScorePanel.vue`
+ `src/components/StudentScorePanel.vue` + Agent 工具 `import_score_sheet`）。

## 功能入口

| 入口 | 行为 |
| --- | --- |
| 班级详情页「考试成绩」Tab | 三种视角：**按考试**（考试按大考/小考分组、可折叠 + 班级统计卡 + 科目统计 + 明细表含排名/档位进度条）、**按学生总览**（学生 × 各次考试总分矩阵 + 班级平均行）、**成绩趋势**（多次考试同时存在时的班级均分柱状图 + 逐次统计 + 各科平均分趋势矩阵） |
| 班级详情页「考试成绩」Tab 工具行「等级映射」 | 配置「分数 → 等级」的分数线与名称（本机保存，改完立即对班级统计/个人成绩生效） |
| 班级详情页「考试成绩」明细表点击任一分数 | **改分纠错**：弹出对话框修订单科分数（或改/清空为缺考等文字），保存后班级统计、排名、趋势即时重算 |
| 班级详情页「考试成绩」Tab 工具行里「按学生总览」右侧的「导入成绩」图标 | 打开导入对话框（智能识别），可指定考试名与考试时间；自动带上班级上下文，避免同名学生跨班误匹配 |
| 学生详情页「成绩」Tab | 概览统计 + **科目成绩折线图**（大考/小考分 Tab，每条折线一个科目、横轴为按时间排序的考试；悬浮节点看考试名与分数，点击节点后该次明细直接展示在走势图下方） |
| 对 AI 助手说「帮我导入成绩单」 | 助手经 `import_score_sheet` 工具直接导入（确认门后） |
| 「导入花名册」选中一份成绩单 | 检测到成绩单后提示「转为成绩导入」，一键交接（见下文） |

## 数据模型（收敛在初始建表迁移中）

```
exams        id, class_name, name, exam_date, exam_type, note, created_at, updated_at
             -- 一次考试 = 一批成绩；班级沿用 grade_class 文本口径
             -- exam_type：major 大考（期中/期末）| minor 小考（单元/月考等）
exam_scores  id, exam_id, student_id, subject, score, grade, created_at, updated_at
             UNIQUE(exam_id, student_id, subject)  -- 导入天然幂等
```

表结构与全库一起收敛在 lib.rs 的单一初始建表迁移里（软件未分发、只有本地调试在用，
不做增量迁移）；本地调试库建于该结构之前时，删除 `aprilio.db` 重启应用重建即可。

要点：

- 每批次成绩必须指定**考试名 + 考试时间**（可从成绩单智能提取，也可手动填写）；
  同一班级「考试名 + 考试时间」相同的批次自动复用——重复导入同一份成绩单只更新成绩，
  不产生重复考试
- 科目是**自由文本**（导入时按表头识别归一：「数学成绩」→「数学」），不做科目字典表——
  小学场景科目少而稳定，先保持轻量；总分/排名等汇总列不导入，由系统按明细计算
- `score` 存**真实数字分**；等级（优/良/合格…）不落库，展示时按「等级映射」现算；
  `grade` 只保留非等级文字（缺考/免考/作弊等），不参与统计
- `exam_type` 在导入时按考试名自动判定（命中「期中/期末/统考/联考/模拟」→ 大考，其余小考），
  可在「编辑考试信息」里手动改
- 删除学生连带删除其成绩；删除班级连带删除班级考试批次与成绩（成绩暂不进回收站快照，
  后续如有需求再扩展）；恢复回收站条目不恢复成绩

## 成绩单识别（智能导入核心）

与花名册导入同构（复用 `RosterTable` 解析与姓名列识别），额外识别三类信息：

1. **科目列**
   - 表头命中科目关键词（语文/数学/英语/科学/道法…或「XX成绩/分数」）→ 科目列，
     归一化科目名；命中排除词（学号/电话/日期/班级/姓名…）直接出局
   - 总分/总评/平均/排名等汇总列永不作为科目
   - 无表头或表头不标准时按**内容特征兜底**：绝大多数单元格是 0~1000 的数字 → 视为科目列
     （长数字如手机号/学号/年份天然被 0~1000 值域排除）
2. **考试名 / 考试时间**：从被剔除的标题行（「三年级二班2026年秋季期中考试成绩单」）提取
   （剥掉「成绩单/分数表」等表类后缀），或从「考试日期」列取首个非空日期；
   都没有 → 对话框默认「空 + 今天」，Agent 工具可传 `exam_name` / `exam_date` 指定
3. **姓名列**：复用花名册的规则打分 + AI 识别（置信度低时对话框要求人工选择、
   Agent 工具返回候选列）

已配置模型时叠加一次 AI 结构识别：把标题行与各列表头/示例值交给模型，返回
`{name_column, subjects, exam_name, exam_date}`；列号经规则校验防幻觉，失败自动回退规则结果。

## 导入规则

- 学生匹配：`student_no` → 班级内唯一姓名 → 全局唯一姓名；学号已存在但姓名不同 → 跳过
  （与花名册导入同一防线，避免把成绩写到他人档案上）
- **成绩单即花名册**：成绩单里有而档案里没有的学生**自动建档**（姓名 + 班级 +
  成绩单学号或 `S<时间戳>` 临时学号），Agent 工具可用 `auto_create_students=false` 关闭
- 成绩逐条 upsert（考试 × 学生 × 科目唯一），单条失败不影响整批；逐行/逐条给出原因
- 浏览器演示态仅支持 CSV/TSV/TXT；桌面端支持 XLSX/XLS 等全部表格格式（复用
  `roster_read_table` / `roster_read_text` 解码通道，语义识别在前端）

## 花名册入口的成绩单分流

「花名册智能导入」最常见的起点就是一份成绩单。两条路径都做了识别：

- **对话框**：`ImportRosterDialog` 智能模式下检测到科目列时展示横幅
  「这更像一份成绩单」→「转为成绩导入」把已解析表格交接给 `ImportScoreDialog`
  （或「仍按花名册导入」忽略）
- **Agent 工具**：`import_student_roster` 加载文件后先做成绩单检测，命中即转入
  `runSmartScoreImport` 管道，一次完成「学生建档 + 智能生成考试批次 + 成绩关联」，
  并在回复里说明两件事都做了；置信度低时仍按花名册导入（宁缺勿滥）

## Agent 行为

- **工具** `import_score_sheet`（dangerous，需 `confirm:true` 确认门）：
  1. `file_path` 缺省时弹出系统文件选择框；浏览器演示态明确报错
  2. 底层即智能成绩导入管道（`runSmartScoreImport`），与对话框行为一致
  3. 参数可覆盖自动识别：`exam_name` / `exam_date` / `class_name` / `name_column` /
     `auto_create_students`
  4. 汇总回复：考试批次（新建/复用 + 名称 + 时间）、识别科目、成绩条数、
     匹配/建档/跳过/失败计数与样例
- 成绩已关联到学生档案后，助手可引导学生去「班级管理 → 考试成绩」或学生详情页查看

## 样例成绩单与模拟导入

`docs/examples/` 下提供多份不同格式的成绩单样例，覆盖智能导入的关键识别路径：

| 样例 | 格式特征 |
| --- | --- |
| `成绩单-四年级一班-期中.csv` | 标准表头 + 标题行 + 班级列 + 考试日期列 + 总分/班级排名干扰列 |
| `成绩单-四年级一班-期末.csv` | 科目顺序不同 + 平均分汇总列 |
| `2026年秋季第一单元测验成绩单.csv` | 无标题行 + 姓名列不在首列 |
| `成绩单-四年级一班-第一次月考-等级制.csv` | 等级制（优/良/合格/待提高）+ 应忽略的综合评定列（导入时按等级映射折算为数字分） |
| `2026年秋季学情摸底测试成绩单.tsv` | 制表符分隔 + 考场/监考噪声列 + 汇总列 |
| `成绩表样例.csv` | 既有样例（标题行 + 多科 + 缺考） |

模拟导入：`tests/score-import-simulation.test.ts` 用**真实导入管道**
（`parseRosterTable` → `runSmartScoreImport`，与对话框 / Agent 工具同源）跑通全部样例，
并把**成功记录**写入 `docs/examples/模拟导入记录.json`（仅成功项，`npm test` 时重新生成）。
该测试同时校验幂等：重复导入同一份成绩单只复用批次、覆盖成绩、不重复建档。

浏览器演示态的 `db.ts` 种子数据为**多班级 × 多次考试**（纯数字分）：
四年级一班（10 人 × 5 次：学情摸底/第一单元测验/月考/期中/期末，与样例同源，含大考与小考）、
三年级二班（林知远 / 苏晚 × 3 次，逐次进步）、其余班级各 3 次。
打开任意班级「考试成绩」或任一学生详情页「成绩」，都能直接看到多次考试的对比与趋势。

## 成绩展示（班级 / 个人）

统计口径统一收敛在 `src/lib/score-analysis.ts`（纯函数，界面与 AI 分析器共用）：

- **只统计数字分**：非数字文字（缺考/免考…）不参与均值与排名，单独展示
- **单科满分按 100 计**（无满分字典）；**总分及格/优秀线**按「科目数 × 及格线 / 优秀线」折算
- **排名**：按总分/单科降序，并列同名次（1、1、3 密集口径），无数字分不参与
- **等级**：由分数按「等级映射」派生（默认 优秀 ≥90 | 良好 ≥80 | 及格 ≥60 | 待提高 <60），
  用于配色、进度条与等级标签；改配置后及格率/优秀率口径同步变化

班级面板：统计卡（均分/最高/最低/及格率/优秀率/参考人数）→ 科目统计表 → 明细表（排名列 +
分数档位配色 + 总分等级标签 + 进度条）→ 按学生总览（班级平均行）。

### 考试种类与折叠

考试批次按 `exam_type` 分为**大考**（期中/期末等）与**小考**（单元测试/月考等）两组；
「按考试」视角里两组各自可折叠，默认只展开当前选中考试所在组——考试多时标题不再铺满一屏，
折叠的组在标题上提示「当前：XX」。导入时按考试名自动判定，也可在「编辑考试信息」里改。

### 等级映射（分数 → 等级）

成绩只存真实分数，等级是**展示期派生**的，规则在成绩页「等级映射」里配置：

- 四档（优秀/良好/及格/待提高）各自可改**名称**与**分数线**，保存在本机 localStorage；
- 改完立即作用于班级统计卡、明细表总分等级标签、个人成绩与趋势配色、以及及格率/优秀率口径；
- 导入**等级制**成绩单时，「优/良/合格…」按该映射折算成代表分落库（如 优→90、良→80），
  非等级文字（缺考/免考）仍原样保留。

**多次考试同时存在时**（关键设计）：

- 班级面板新增「**成绩趋势**」视角：
  - 班级平均单科分柱状图（按考试时间从左到右，**用 0~100 的单科均分而不是总分**——
    总分随科目数变化（3 科 vs 5 科）不可比，单科均分才可比）；
  - 逐次考试统计表（参考人数 / 平均单科分 / 及格率 / 优秀率）；
  - 各科平均分趋势矩阵（科目 × 考试，档位配色）。
- 个人面板新增「**多次考试对比**」区块：
  - **科目成绩折线图**（纯 SVG，无图表库）：**大考 / 小考用 Tab 切换**（不并排堆在一栏，
    只有一类考试时不显示 Tab），**每条折线 = 一个科目**，
    横轴为该类考试按时间正序排列的考试名 + 日期；缺考的点断开不连线，单次考试只画数据点；
  - **纵轴自适应**：不再固定 0~100，而是按本次数据的最高/最低分自动收紧（如 92~97 → 纵轴
    90~100），并保证至少 15 分视野、常规百分制不越过 100——折线在上下限之间铺开，区分度更高；
    纵轴范围在图例右侧以「纵轴 90~100」明示；
  - **命中按列划分**：每次考试占一整列热区（铺满绘图区高度），取离光标最近的点，节点再密也能
    选中；同一列上下移动可在科目之间切换；相邻考试间距不足时图表横向滚动，避免挤在一起；
  - **交互**：悬浮提示「这是哪次考试 + 该科分数」；**点击**后该次考试的明细卡
    **直接出现在这张走势图下方**（再点一次收起）——默认不把每场考试都铺开，避免页面过长；
  - 展开的明细卡沿用原样式（总分徽标 + 班级排名 + 较上次进退步 + 各科分数/班均/单科排名 + 进度条）。

个人面板整体顺序：概览卡（参考考试/平均总分/最好总分/最近排名）→ 成绩走势图（点击节点看该次详情）。

## AI 能力登记（成绩数据）

成绩数据以「能力」形式登记进 AI 框架，助手可随时取数与分析：

| 能力 | 位置 | 说明 |
| --- | --- | --- |
| `query_data` 实体 `exams` | `src/agent/tools/query.ts` | 按班级/考试名/种类（`exam_type`：大考/小考）查考试批次（带科目数/成绩数/学生数） |
| `query_data` 实体 `scores` | 同上 | 按班级/考试 ID/学生/科目查成绩明细 |
| `analyze` 内置分析器 `score-analysis` | `src/agent/analysis/providers/score-analysis.ts` | kind：`score_overview`/`score_class`（班级统计+排名）、`score_student`（个人报告+偏科诊断）、`score_rank`（排行榜）、`score_trend`（走势：传 student_id/姓名 → 个人；传 class_name → 班级多次考试趋势） |
| MCP 只读工具 `list_exams` / `get_exam_scores` | `src-tauri/src/mcp_server.rs` | 外部 Agent 客户端（Goose / Claude Desktop）读取考试批次与成绩明细 |

分析器在 `src/agent/tools/analyze.ts` 装配时经 `registerScoreAnalysisProvider()` 幂等注册进
`defaultAnalysisEngine`；统计口径与界面共用 `score-analysis.ts`，保证「助手说的数字」与界面一致。
典型问法：「四年级一班期中考试平均分和排名」「赵晨曦成绩怎么样、有没有偏科」「期末谁第一」。

## 设计约束

- 与花名册导入共用文件解码、表格解析与姓名列识别（`src/lib/roster.ts`），
  `scores.ts` 只做成绩语义（科目列 / 考试信息 / 成绩单元格 / 学生匹配）
- 考试批次幂等：`findOrCreateExam` 按（班级，考试名，考试时间）复用；
  成绩幂等：`upsertExamScore` 按唯一键覆盖
- 日志只记计数与文件路径，不落学生姓名/成绩等隐私字段
- `RosterTable.titleText`：表头嗅探剔除的标题行文本被保留下来供考试信息提取，
  花名册导入不受影响

## 验收清单

- [ ] 班级详情「考试成绩」Tab：导入一份含标题行的成绩单 → 考试批次自动带名与时间
- [ ] 导入对话框：考试名/时间可手动修改；总分列被忽略；缺考显示为文字
- [ ] 重复导入同一份成绩单 → 不产生重复考试、不重复建档，成绩更新
- [ ] 改成绩单里的分数重导 → 对应学生成绩被更新；学号相同姓名不同 → 跳过
- [ ] 成绩单里的新学生 → 自动建档且出现在学生列表（带成绩单学号）
- [ ] 班级总览矩阵：每个学生每次考试的总分正确（含纯等级列显示「优」），底部有班级平均行
- [ ] 班级面板：统计卡/科目统计/排名与档位配色正确（与 `score-analysis.ts` 口径一致）
- [ ] 考试按大考/小考分组、可折叠；「编辑考试信息」可改种类，改后分组即时变化
- [ ] 「等级映射」改分数线/名称 → 明细表总分等级标签、配色与及格率/优秀率同步变化
- [ ] 导入等级制成绩单 → 成绩落库为数字分（优→90 等），缺考等文字仍保留
- [ ] 点击明细表任一分数 → 可改分（如 95→91）或清空该科；保存后总分/排名/统计/趋势同步更新
- [ ] 多次考试：班级「成绩趋势」正确（单科均分口径）；个人成绩走势图大考/小考 Tab 切换正确
- [ ] 学生详情「成绩」Tab：科目折线图按大考/小考分组、每科一条线、横轴按时间排序；缺考断开
- [ ] 折线图节点悬浮提示考试名与分数；点击节点才展开该次考试明细（再点收起），默认不铺开
- [ ] 学生详情「成绩」Tab：历次考试按时间倒序，单科与总分正确，带班均/排名/进退步
- [ ] `docs/examples` 样例全部可导入 → `模拟导入记录.json` 只含成功项，重复导入不产生重复批次
- [ ] 「导入花名册」选一份成绩单 → 横幅出现，「转为成绩导入」可交接
- [ ] 对助手说「直接导入成绩单 <路径>」→ 确认门拦截后按成绩导入并生成考试
- [ ] 对助手说「四年级一班期中平均分和排名」→ `query_data` + `analyze` 给出与界面一致的统计
- [ ] 删除考试批次 → 成绩一并删除，学生档案不受影响；删除学生 → 其成绩清除
