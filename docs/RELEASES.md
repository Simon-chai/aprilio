# 发版记录与兼容性基线

本文是版本的兼容性基线与发版台账。**自 v1.0.0（第一版发版）起，所有改动必须往前兼容**：
用户升级后，既有数据库、本机存储、导入过的文件与 Agent 调用必须继续可用。

## 兼容性总则

需要守护的兼容面：

| 面 | 说明 |
| --- | --- |
| 数据库结构 | 建表迁移收敛在 `src-tauri/src/lib.rs`（当前是单一初始建表，不做增量迁移）；v1.0.0 起用户库里已有数据，新增字段一律「加列 + 代码兜底默认」，禁止依赖删库重建 |
| 本机存储 | localStorage 键名与 JSON 结构（等级映射、图表偏好、模型配置、背景索引等）；`aprilio.db` 路径与内容；`photos/`、`backgrounds/`、`pets/` 目录约定 |
| 导入 / 导出格式 | 花名册模板、成绩单样例、课表导入的列语义只能在旧口径上扩展，不能改旧列的含义 |
| Agent 接口 | `src/agent/tools/*` 的工具名与参数语义只增不改；应用内 MCP 只读工具面（`src-tauri/src/mcp_server.rs`）同理 |

破坏性变更（确需时）：必须同时提供**迁移或兼容读取**（旧数据自动升级 / 新代码读到旧数据不崩），
并在本文对应版本下登记「破坏性变更」一节。

## v1.0.0 · 第一版发版（2026-09-27）

首个功能完整的发版基线，版本号 `1.0.0`（`package.json` / `src-tauri/tauri.conf.json` /
`src-tauri/Cargo.toml` 三处一致），git tag `v1.0.0`。功能面：

- **学生档案与班级**：班级管理（含归档的历史班）、学生详情（基本 / 监护人 / 照片 / 表现 / 成绩 / 学期）、
  回收站（7 天可恢复）、全局搜索
- **导入**：花名册智能导入（规则 + AI 姓名列；双行分组表头、最多两位监护人与单位/职务合成、忽略列可见）、
  成绩导入（成绩单识别、考试批次幂等、自动建档、档案缺学生即花名册）、课表导入；
  整批无班级信息时由 AI 从文件名 / 标题行推断班级名（如「四8班学生详细信息.xlsx」→「四8班」）
- **成绩**：班级 / 个人成绩面板、五种分布图型、等级映射与「只显示等级」、排名与趋势、
  AI 成绩分析（`analyze` 内置分析器，口径与界面同源）
- **学期化**：成绩 / 表现 / 作业 / 评语按日期自动归属学期，学生详情可切学期回看
- **课程表**：班级全科课表（万年历 + 备忘 + 网格编辑）与「我的课表」按任教学科聚合
- **Agent**：能力容器 + 工具注册表 + 页面动作、写操作确认门、Rig + rmcp 双轨（应用内 MCP server
  只读工具面）、流式输出、RAG 语义搜索（Ollama embedding）
- **课堂模式**：节课 = 会话容器 × 可组合活动 × 统一事件流（v9 四表），崩溃重放恢复
- **界面与体验**：设计系统 token 与 design-token-guard 防退化门禁、背景图库、桌面宠物、评价报告

兼容性：本版为基线，无历史版本需要兼容。
