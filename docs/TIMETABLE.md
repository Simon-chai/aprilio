> ① **不做教师名绑定**。单人本地工具里教师名是自由文本，按名字匹配脆弱且多余；改为「我的科目」集合绑定——我教哪些科目，班级课表里这些科目的格子就是我的课。课表格子不存教师名。

## 1. 定位与现状

班主任场景里，课程表是每天打开频率最高的信息：早上看「今天有什么课」、上课前看「下一节是什么」、跨班任教时问「我这门课什么时间要去哪个班」。

aprilio 现状缺口：

- 没有课程/节次概念，无法承载课表
- 「课堂表现」维度（behavior_dimensions.classroom）记录时没有科目上下文，无法按科目回看
- 首页首屏的「秋季学期」是写死文案（HomeView.vue 模板），没有学期概念兜底；个人资料也登记不了任教学科

只做两个视图，别的不做：

- **班级全科课表**：一班一学期一张周网格，手工编辑或 Excel 导入
- **我的课表**：从全部班级课表里按「任教学科」聚合出的个人行程（纯推导，不落库）

边界：不是教务排课系统——不排教师冲突、不管其他科任老师的课、不考虑走班选课、不考虑周六补课。定位是「查」和「给其他功能提供场景上下文」的底座。

## 2. 数据模型（迁移 v1 全量建表 + v3 课表补齐 + v4 调课/日程事件 + 前端 ensureSchema 兜底）

> 2026-09-07 起迁移分三版：v1 收敛全量建表；v2 与历史调试库已占用的版本号对齐（幂等空转——版本号只增不复用，否则新迁移会被旧记录跳过）；v3 幂等补齐课表/万年历表；v4 幂等补齐调课例外/日程事件，并把 `calendar_memos` 数据迁入 `calendar_events`（type='memo'）后删表；v6 幂等补 `timetables.my_subjects` 与 `profile.timetable_bg`。`profile.my_subjects` 列与全部表结构另由前端 `ensureSchema`（src/lib/db.ts，启动时执行，tests/schema-sync.test.ts 与迁移对账，legacy 表单独豁免）幂等兜底——迁移历史再乱也不会出现「no such table」。

```sql
-- 课表：一班一学期一张（班级沿用 grade_class 文本口径，与 exams 一致）
timetables      id, class_name, semester, note, periods_json,
                created_at, updated_at
                UNIQUE(class_name, semester)

-- 格子：一行 = 一节课；空格子不落行。【唯一事实源】
timetable_slots id, timetable_id, day_of_week, period,
                subject, note, updated_at
                UNIQUE(timetable_id, day_of_week, period)   -- day_of_week 1=周一 … 5=周五

-- 调课例外：某班「某天某节」对周课表的一次性覆盖（换课/停课/加课）
timetable_exceptions id, timetable_id, exception_date, period,
                subject, note, created_at, updated_at
                UNIQUE(timetable_id, exception_date, period) -- subject 空串=停课
                -- 星期几由 exception_date 推导，不落列（避免与日期不一致）

-- 「任教学科」挂在教师个人资料上：我教哪些科目（JSON 数组，如 ["语文"]）
profile         … 现有列不变，新增 my_subjects TEXT

-- 统一日程事件：班级日历与教师课表共用（class_name NULL = 教师个人事件）
calendar_events id, class_name, event_date, type, period, content, done,
                created_at, updated_at
                INDEX(event_date)、INDEX(class_name, event_date)
                -- type ∈ memo|todo|exam|homework；done 0/1（考试也可勾「已处理」）
                -- period 绑定节次（1 起）；NULL = 全天/日报事件，不落在具体课表格子
```

要点：

- **一班一学期一张**：换学期建新表不覆盖旧表，历史课表可查。semester 文本如 `2026-2027-1`
- **学期号纯函数推导**（`lib/timetable.ts` 的 `currentSemester(date)`）：
  9~12 月 → `Y-(Y+1)-1`（秋季）；1~2 月仍属上一年度秋季 → `(Y-1)-Y-1`；3~8 月 → `(Y-1)-Y-2`（春季）。
  无需任何设置项，首页写死的「秋季学期」顺带替换为推导标签
- **格子天然幂等**：同一 (节, 天) 唯一，编辑即 upsert，清空即删行——与成绩导入同一手感；调课例外同构（(日期, 节) 唯一）
- **科目自由文本 + 预设胶囊**：预设与成绩导入的科目关键词同口径（语文/数学/英语/道法/科学/体育/音乐/美术/班会/自习/晨读/劳动…），不做字典表；格子 `note` 选填（如「去机房」），浮层里一个可选小输入
- **「任教学科」存 profile**：`my_subjects` JSON 数组，是「我的课表」的唯一判定条件（trim 后与格子科目精确相等）；**主录入入口在个人资料页**（§3），候选 = 库内课表实际出现过的科目 + 预设科目，即点即存，天然对得上，不需要任何姓名匹配
- **节次配置随课表存 JSON**（`periods_json`），不建第三张表：`[{period, session: morning|afternoon, start, end}]`。
  默认小学 8 节（上午 4 节 08:00 起，下午 4 节 14:00 起），可增删节次、改时间；时间全空时界面只显示节次序号
- **日程事件只有一张表**（决策 ⑥）：班级维度与教师维度是同一张 `calendar_events` 的两个过滤口径，杜绝两套日程互相漂移；删班级连带删其班级事件，个人事件不受影响
- 删除班级连带删除其课表（含调课例外）；课表**不进回收站快照**（与成绩同口径，后续有需求再扩展）

## 4. 班级全科课表（周网格 + 日历）

班级详情「课程表」Tab **默认是一张完整周网格**；「日历」是同一课表的日期投影与调课/日程维护视图：

- 进入 Tab 即看到行=完整节次、列=周一~周五的可编辑网格；**没有任何课程也照常显示所有节次**，点格子选择科目/备注
- 顶部「课表 / 日历」切换；日历格子仍有悬浮交互，右上角有「编辑课表」快捷入口，便于从日期视图回到周网格
- 网格工具行保留「节次设置」；日历侧维护单日换课、停课、恢复、加课与日程事件

### 4.1 周网格与编辑

- 布局：**列固定周一~周五**，**行 = 节次**，按 morning/afternoon 分组并留组间空隙
- 点格子 → 浮层：科目预设胶囊点选 + 自由输入 + 备注（选填），底部「清空」
- **保存时跨班撞课检测**（决策 ㉒）：待保存科目 ∈ 本班生效我的科目、且其他班同（天，节）有「我的课」→ 浮层内出红色警告条（逐条列 `周X 第N节 · 班级（科目）`），按钮变「仍要保存」需二次确认；改科目/备注即重置，清空格子不检测
- **列头全天备忘**（决策 ㉓）：星期列头兼任本班全天备忘入口——显示该班该天不绑节次的日程事件（最多 2 条 + 溢出数），点列头展开编辑器速记（类型色点下拉 + 回车保存，勾选完成 / 删除，AI 快速浏览标题），备忘绑本班、挂本周对应日期；与格子课程编辑浮层互斥开合
- 「节次设置」弹窗：节数增删、上/下午归属、上下课时间
- 视觉遵循设计系统的克制：格子中性底色（pearl/canvas）+ 发丝线，**只有今天列和当前节次用 Action Blue 描边**；「任教学科」的格子加一个轻量标记（科目文字下加 Action Blue 小圆点），在自己的班课表上一眼认出自己要上的课

## 5. 万年历（课程与备忘的统一载体）

日历视图的展示主角是**月历**，周网格视图的展示主角是完整节次表；两者是同一课表事实的不同投影。

- **网格**：固定 6 周 × 7 天、周一起始（`lib/calendar.ts` 纯函数，跨月前后补齐）；上月/下月切换、「回到今天」
- **课程上日历**：周课表按「日期 → 周几」映射，每一天显示当天科目（**先套用该天调课例外再展示**，停课不占位；去重，最多 2 个 + 溢出数），科目用稳定配色小胶囊，随月份自动重复；周课表是唯一事实源，日历永远是其投影
- **调课在日历上维护**（决策 ⑤）：日详情面板的课程列表每行悬浮出「换课 / 停课」操作（内联科目胶囊选择），被调过的行显示「调 / 加 / 停」徽标与「恢复默认」；空节次可「＋ 加一节」。所有操作只写 `timetable_exceptions`（挂在选中日期上），周课表不变
- **日程事件（calendar_events）**：绑当前班级、按天挂载，类型 = 备忘/待办/考试/作业（色点区分），可勾选完成、删除；右侧日详情面板选类型 + 录入（输入 + 回车）；网格格子上显示条目（类型色点 + 内容，完成划线）
- **日详情面板**：选中某天 → 右侧显示该天实际课程列表（第 N 节 + 科目胶囊 + 调课徽标 + 备注）与全部日程事件；默认选中今天
- **今天 / 选中态**：今天 = Action Blue 实心日期圆点；选中天 = primary-soft 底 + 主色描边
- 删除班级连带删除其班级日程事件；浏览器演示态给一批本月示例事件（含考试/待办/个人事件）与两条调课例外（停课 + 加课）

## 6. 我的课表（完整周网格 + 按科目聚合，纯视图）

**不落库、无新表**：我的课表 = 当前学期全部班级课表格子中，`subject ∈ profile.my_subjects` 者的投影。
同一科目在多个班都有课 → 这就是「这门课，什么时间要去哪个班」的答案。

### 6.1 数据与推导

- `db.ts` 提供 `listTimetableSlotsWithClass(semester?)`（timetable_slots join timetables 取回 class_name）、`listTimetableExceptionsWithClass(semester, start, end)`（调课例外联班级名）、`listTeacherEventsInRange(start, end)`（教师维度日程：班级事件 + 个人事件）、`listTimetableSubjects()`（库内 distinct 科目，供个人资料页多选候选）与 profile 的 `my_subjects` 读写
- 纯函数 `buildMySchedule(rows, mySubjects)`（`lib/timetable.ts`，vitest 直测）：
  - `bySubject[]`：按科目分组，组内会话按 周几 → 节次 排序，附每科周课时数与总课时
  - `conflicts[]`：任教学科在同一 (天, 节) 出现在多个班级 → 冲突对列表（各班课表独立维护，跨班撞课只有聚合时才能发现）
- 纯函数 `resolveDaySlots(baseSlots, dayExceptions)`：把某天的调课例外套到周课表上，得到逐节实际课程（normal/changed/added/cancelled 四态，停课保留原科目供划线展示）；`buildMyDays(rows, exceptions, mySubjects, dates[])` 进一步按班级聚合并过滤任教学科——**换成别人的课我这节消失，我的课被停保留划线，别的课调成我的科目则出现**。首页「今天」、我的课表「本周日程」、Agent「今天」三处共用这套投影，保证三处看到的是同一份事实

### 6.2 界面

- **任教学科只读展示**：页顶胶囊显示当前 `profile.my_subjects`，附「去个人资料调整」链接；配置只有一个入口（个人资料页），避免两处编辑
- **周课表（默认形态）**：带日期的完整周网格（列头 = M/D + 周几，今天高亮，**列头兼任全天日程入口**：显示该天不绑节次的事件（最多 2 条 + 溢出数），点击展开全天编辑器；行 = 全部节次，不因「我有课的节次」缩水，**节次列只显示序号**），格子 = 我的课在**调课后**的实际形态（科目胶囊按稳定配色，停课划线带「停」徽标、换课/加课带「调 / 加」徽标）+ **绑定该格的备忘**（类型色点 + 内容，完成划线，班级事件附班级名）；**点击任意格子展开格内编辑器**：记 / 管「日期 × 节次」的备忘（勾选 / 删除 / 回车速记），课程格附「去班级 →」跳转；类型胶囊只在课表卡片右上角一处（图例 + 速记类型选择）
- **跨班备忘自动合并**（决策 ㉓）：教师维度查询（`listTeacherEventsInRange`）本就含班级事件 + 个人事件——各班课表列头/日历记的备忘与个人备忘在同一网格自动合并，无需任何手动同步；班级条目带班级名小字区分，备忘无排课冲突不做冲突检测；在我的课表速记的备忘不绑班级（个人事件）
- **按科目分块（切换形态）**：每个科目一张卡片——科目名 + 周课时数 + **完整节次 × 周一~周五表格**，格子 = 班级名，配置了时间则附时间，空格淡显；科目卡片按周课时数降序
- **冲突告警**：`conflicts` 非空时页顶横幅列出（`周一 第3节：语文在 三(1)班 与 三(2)班 冲突`），点击跳对应班级课表修改
- **空态引导**：未登记任教学科或还没有命中课程时，显示「登记任教学科 → 导入 Excel/CSV → 去班级手工排课」三步引导；完整周网格与日程不被拦截
- 学期默认取 `currentSemester()`；切换历史学期放下拉（P2，数据层天然支持）

## 7. 首页「课程表」（半透明直展，决策 ⑦/⑨）

首屏布局（2026-09-07 三轮定稿）：**时间信息收在左下角**（学期/时钟/日期/问候），**课程表入口常驻左侧中间**，展开面板**首页居中**。

- **入口按钮**（`absolute left-12 top-1/2`，玻璃胶囊）：日历图标 + 「课表」+ 今天节数角标（有课时显示，未登记任教学科或没课不显示）；面板打开时按钮高亮，**再点即收**——一键展开/收起始终可用
- **展开面板**（居中：`left-1/2 top-1/2` 平移居中，`w ≤ 880px`、`max-h 76vh` 内部滚动）：
  - **遮罩**：面板打开时全屏 `bg-black/40` 遮罩压暗背景文案（时间/问候不再透出来搅局），点空白处即收起
  - **半透明周课表**：列 = 周一~周五（列头带 M/D，今天列高亮），行 = 节次序号；格子 = 我的课在**调课后**的实际形态（科目色点 + 班级，玻璃小卡；停课划线带「停」徽标，换课/加课带「调 / 加」徽标；今天列的当前节次卡加 primary-on-dark 描边表示「现在」）——课表本体直接呈现在首页，不用跳页
  - **今日日程**：班级事件 + 教师个人事件（附班级名），类型色点区分，可勾选完成、可删除；底部类型胶囊（备忘/待办/考试/作业）+ 输入框回车速记个人事件
  - 头部右侧「完整课表 →」进 `/timetable`
  - 未登记任教学科：网格照常显示（空格子），下方一行提示「登记任教学科后，这里显示你跨班的课；日程不受影响」
- **第二屏「课程表」常驻卡**：描述只放短句（`每周 N 节 · 今天 M 节` / 任教学科列表 / `排课 · 调课 · 日程`），右侧带今天课程速览胶囊，点击进 `/timetable`——作为第二层常驻入口兜底

首页**只读不编辑周课表**：换课/停课/加课、节次设置等复杂操作全部收在班级万年历与 `/timetable` 页。浏览器演示态给一份示例课表 + 示例日程（含个人事件），双态行为一致。

## 8. 导入（已实现，2026-09-07）

与花名册/成绩导入同构，复用 `roster_read_table` + `RosterTable` 解码管道，课表语义收在 `lib/timetable-import.ts`：

## 9. Agent 行为

- **工具** `query_timetable`（只读，safe 级）：参数 `class_name?` / `mode: "class" | "mine"` / `semester?` / `date?` / `weekday?`（日期缺省今天）；
  `class` 走班级全科课表投影，`mine` 走「我的课表」聚合投影（按科目分组的文本摘要）；返回附页面动作引导跳转对应页面
  （`src/agent/tools/timetable.ts`，经容器扫描注册，同现有工具扩展步骤）
  - 典型问法：「今天有什么课」「我周二要去哪些班」「三(2)班周五课表」「我周三第2节在哪个班」
  - 问「今天」（缺省或显式指认今天）：先套用当天调课例外（`buildMyDays`），摘要标注「已考虑当天调课」并逐条给出停课/换课/加课变化，末尾附带**今日日程**（`listTeacherEventsInRange`：班级事件 + 个人事件，含类型与完成状态）
  - 显式问其他周几：按周课表基准推算，摘要注明「未考虑具体某天的调课」（例外挂在具体日期上，跨周推算不适用）
- **写操作后置**：`import_timetable`（dangerous 级，confirm 确认门，与 `import_score_sheet` 同规格）随导入功能（P1）一起做

## 12. 设计约束

- **科目绑定，不绑教师名**（决策 ①）：「我的课表」唯一判定条件是 `subject ∈ profile.my_subjects`，没有姓名匹配；教师身份 = 个人资料里登记的任教学科
- **周课表是唯一事实源，其余全是投影**：我的课表（按科目聚合）、带日期的本周行程（套例外）、班级日历上的课程，全部从 `timetable_slots` 推导；调课例外只覆盖单日、绝不回写周课表；日程事件只有 `calendar_events` 一张表，班级/教师是同一事实的两个过滤口径——任何界面都不存在第二份真相
- **维度分工**：班级课表（班级全科事实，万年历 + 网格编辑）在班级详情页；教师课表（跨班行程 + 日程）在首页轻灵入口与 `/timetable` 页——不同维度不同界面，共享同一底座
- 轻量：科目、节次都不建字典表；`periods_json` 只放展示性配置，逻辑判断不依赖时间（没配时间就退化）；调课例外不建「调课单」实体，一个覆盖行就是全部事实
- 复用：文件解码解析走 `roster.ts` 管道；纯函数收敛在 `lib/timetable.ts`，与 `db.ts` 分离可直测；毛玻璃面板复用设计系统的 `glass-dark` utility
- 一致口径：班级用文本、初始迁移收敛建表、浏览器演示态内存数据、回收站策略与成绩对齐
- 隐私：课表与日程不含学生个人信息，日志可记班级名/科目与格子数
