# 学生单科成绩趋势分析

## 背景

学生详情页「成绩」Tab 目前只有两种视角：单场考试的各科柱状图 + 全科每科一条线的走势图，无法聚焦某一科看趋势；班级均分、单科排名这些已有数据只在点击节点后的详情文字里出现，图上看不到对比，显得单调。

数据层无需改动：`getStudentScoreReport`（src/lib/db.ts:3473）已返回每场每科的 `score / class_average / class_rank`，本功能是纯前端下钻。

## 交互设计

在「多次考试对比」区（`data-test="multi-exam-section"`）的走势卡片里，标题行下方加一排**科目芯片**：`全部 | 语文 | 数学 | …`（带色点，颜色用 `chartColorOf` 与全科图折线一致）。

- **全部（默认）**：现有全科折线图，行为完全不变；
- **选单科**：切换为单科透视视图，自上而下：
  1. **单科统计条**（6 格，样式对齐现有概览统计条）：平均分 / 最高分 / 最低分 / 波动（最高−最低）/ 最近一次较上次（↑↓ 分数）/ 最近名次（第 N 名，附较上次升降）；
  2. **趋势对比折线图**：复用 `ScoreLineChart`，两条线——本人该科分数（实线、该科色）+ 班级均分（虚线灰，作参照）；缺考/无班均数字的点断线；悬浮 tooltip、点击节点展开该次考试详情卡（复用现有 `exam-card`，单科模式下该科目行高亮）；
  3. **趋势小结**：一行规则生成的中文摘要，如「语文 3 次考试平均 88.5 分；最近一次 92 分，较上次 ↑5，高于班均 4.2 分；班级排名第 2，较上次 ↑1」；
  4. **历次名次一览**：横向 chips 按时间正序，每场「第 N 名」+ 较前一场升降箭头（进步绿/退步红，沿用 tag-positive/negative 语义色）。

大考/小考 Tab 与学期过滤继续生效（单科视图画的是当前 Tab 的考试序列）；切换 Tab/学期后若所选科目无数据，自动回退「全部」。

## 实现步骤

1. **`src/types/index.ts`**：新增 `SubjectTrendPoint`（examId/examName/examDate/score/grade/classAverage/classRank/classStudentCount）与 `SubjectTrendSummary`（points + stats：count/average/max/min/range/latestScore/latestDelta/latestGapToClassAvg/bestRank/latestRank/rankDelta）。

2. **`src/lib/score-analysis.ts`**：新增纯函数 `summarizeSubjectTrend(exams, subject)`（exams 为按时间正序的 `StudentExamReport[]`）。只统计数字分，class_average/class_rank 为 null 时容错；仅 1 次成绩时 delta/gap/rankDelta 为 null。聚合口径按仓库约定收敛在此文件。

3. **`src/components/ScoreLineChart.vue`**：series 增加可选 `dashed?: boolean`，渲染时 `stroke-dasharray="6 4"`，让班级均分参照线视觉弱化。tooltip/断线/热区/纵轴逻辑不动，向后兼容。

4. **`src/components/StudentScorePanel.vue`**：
   - 抽出全局科目顺序（按首次出现），`chartGroups` 的全科图 series 改用同一顺序，保证大考/小考两图与芯片色点同科目同色；
   - 新增 `activeSubject` ref（null = 全部）与科目芯片行；
   - `activeSubject` 为 null → 现有 ScoreLineChart；否则渲染 `SubjectTrendView`，`point-click` 透传给现有 `onPointClick`/`selectedExamId` 详情卡逻辑；
   - watch 大考/小考 Tab 与学期变化，所选科目无数据时回退「全部」。

5. **新组件 `src/components/SubjectTrendView.vue`**：Props `{ exams, subject, selectedIndex }`，emit `point-click`。内部组装统计条 + ScoreLineChart（series = [本人, 班级均分(dashed)]）+ 趋势小结 + 名次 chips。data-test 齐备：`subject-trend-chips` / `subject-trend-stats` / `subject-trend-chart` / `subject-trend-summary` / `subject-trend-ranks`。

6. **测试**：
   - 新文件 `tests/student-subject-trend.test.ts`：按仓库惯例（内存 DB 种子 → mount StudentScorePanel → flushPromises → data-test 断言）。种子：3 名学生、3 场考试（含大考/小考）、2~3 科。断言：默认「全部」视图不回归；点科目芯片后统计条数字精确、两条折线、小结文本、名次升降；点节点展开 exam-card / 收起；单科模式下大考/小考 Tab 仍生效；缺考（grade）不参与统计。
   - `tests/score-analysis-lib.test.ts` 补 `summarizeSubjectTrend` 纯函数用例（并列名次、null 容错、单场考试 delta=null）。

7. **验证门禁**：`npm run typecheck` → `npm test`（AGENTS.md 全局约定；未动 Rust，不需要 cargo check）。

## 非目标

- 不引入图表库（保持纯 SVG 约定）；
- 不做总分趋势线（科目数不同的考试总分不可比，见 score-analysis.ts:253 口径注释；总分概览已有统计条）；
- 不动班级页趋势视图与 AI 分析器。
